He is the author of Python Pedia, a structured beginner-level book designed to help students build a solid foundation in Python programming. His technical skill set includes HTML, CSS, JavaScript, PHP, Python, and C along with practical exposure to data science concepts, linear algebra, basic machine learning, and API-based AI systems.

### Security Research & Highlights
At the age of 16, Inaam independently identified and responsibly reported six security vulnerabilities across three different websites. These included a PII-leaking API, company credentials exposure, an authentication-related community ban bypass, and business logic flaws that allowed unauthorized manipulation of likes and engagement metrics. He also identified a web application vulnerability through experimentation, contributing to the improvement of the site’s like/dislike system.

Currently a student preparing for medical entrance exams while pursuing technology as a parallel passion, his long-term goal is to build research-driven technology particularly in AI, healthcare and cybersecurity that creates real-world impact.
